# Для любого ИИ-агента

Память проекта — папка [`.memory/`](.memory/README.md). **Начни с `.memory/README.md` и следуй ему**: в начале прочитать STATE, последние 3 записи `log/`, DECISIONS; по ходу разговора — конспектировать его новыми записями в `.memory/log/`.

Код приложения меняется только после слова «Программируй». Версию в `AppVersion.swift` поднимает автоматическая проверка после слияния — вручную не трогать. Общение по-русски, коротко.
