# AeroUchet

SwiftUI-приложение для учёта рейсов, рабочего и полётного времени и плана работ пилота. Разрабатывается в Swift Playgrounds на iPad (`Package.swift` генерирует Playgrounds). Номер версии — `AppVersion.swift`.
