# AeroUchet

Рабочая копия проекта «АэроУчёт» из Swift Playgrounds на iPad.

## Проект

Исходный Swift Playgrounds App находится в папке:

`My App.swiftpm/`

В репозитории сохранены:
- `Package.swift`
- все текущие `.swift`-файлы приложения

Служебные файлы `.swiftpm/playgrounds` и превью-изображение не добавлены: Swift Playgrounds создаёт их автоматически.

## Базовая версия

Эта версия импортирована из рабочей копии проекта пользователя 24 сентября 2026 года.
