## v129 — ручное задание
- Номер рейса в новом задании вводится/показывается цифрами без `SU` и без дефиса.
- После ухода из поля номера приложение ищет рейс в импортированном расписании и заполняет маршрут/терминалы и времена.
- Плановые времена лега: `engineOn = вылет расписания`, `takeoff = engineOn + 8 мин`, `landing = engineOff − 8 мин`, `engineOff = прилёт расписания`.
- Первый leg: `workStart = engineOn − 1:00`. Последний leg: `workEnd = engineOff + 0:30`.
- Добавление следующего лега: предыдущий `workEnd = previous engineOff`, новый `workStart = previous engineOff`.
- Парный номер строится от последнего реально выбранного лега: чётный → `+1`, нечётный → `−1`; ручная смена номера меняет базу для следующего лега.
- Даты событий хранятся Date и корректно переходят через 00:00 после UTC→Москва.

## v129 — воздушные суда
- `Ещё → Воздушные суда`: справочник RA-бортов с эксплуатационным типом, фамилией, старым бортом и MSN, если известен.
- Рабочие типы: `A320`, `A320S`, `A320N`, `A321`, `A321S`, `A321N`.
- Коды истории: `A-320→A320`, `A-320A→A320S`, `A-320N→A320N`, `A-321→A321`, `A-321B→A321S`, `A-321Q→A321N`.
- В карточке тип ВС выбирается меню из этих 6 вариантов.
- При вводе 5 цифр RA-борта и уходе из поля тип подхватывается из справочника.
- Если при заполненном борте выбрать другой тип ВС, борт очищается.
- Компоновку пока не финализировать; полную БД борта/старый борт/MSN/компоновка дополнять позже.
