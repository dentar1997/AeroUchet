# Поиск рейса и календарь выполнения в базе расписания

**Дата:** 04.10.2026 23:45 МСК
**Агент:** ChatGPT

## Что решил Денис
- В компактном просмотре базы расписания поиск по номеру рейса должен работать по всей загруженной базе, а не только по выбранной дате.
- Если рейс существует, но не выполняется в выбранный день, показывать сам найденный лег/маршрут и подсказку открыть календарь выполнения.
- По календарю показывать дни, в которые найденный рейс реально выполняется по импортированному расписанию.
- Календарь обязан учитывать текущий фильтр семейства/типа ВС: при фильтре A320 отмечать только даты, когда этот рейс выполняется на A320-family; при `Все` показывать все даты/типы.
- Если номер рейса используется на нескольких маршрутах, не объединять их молча: показывать отдельные варианты маршрута, и календарь строить для выбранного варианта.
- Календарь показывает только покрытие реально импортированных периодов; вне загруженного расписания ничего не экстраполировать.

## Предлагаемая UX-логика
1. Пользователь вводит, например, `1456`.
2. Если на выбранную дату есть точная строка — показывается обычная строка расписания.
3. Если на выбранную дату рейса нет, но номер существует в базе — показать найденный маршрут и сообщение `В выбранную дату рейс не выполняется` + действие `Календарь выполнения`.
4. В календаре дни выполнения отмечаются; фильтр ВС сужает набор отмеченных дат.
5. При выборе даты в календаре таблица переходит на эту дату и показывает конкретную строку с её типом ВС и полётным временем.
