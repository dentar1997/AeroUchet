# 04.10.2026 23:54 — замечания по редактированию FlightDuty

Денис проверил карточку задания на полёт в разделе «Полёты» в режиме редактирования.

## Новое замечание по типу ВС / борту
- При тапе по типу ВС и смене типа текущий борт сейчас исчезает полностью.
- Желаемое поведение: после ручной смены типа в поле борта должна оставаться визуальная ошибка/заглушка `—` (как в других аналогичных полях), а не полностью пустое место.
- Для пятизначного борта Backspace должен работать как согласованная двухшаговая логика:
  1. первый Backspace очищает все 5 цифр и оставляет `—`;
  2. второй Backspace не должен удалять `—`; он должен вернуть предыдущий бортовой номер.
- Это относится к редактированию сохранённой карточки FlightDuty и должно быть согласовано с поведением нового задания.

## Поиск рейса в истории
- Денис заметил, что при вводе номера рейса в старой сохранённой истории автоподстановка не сработала.
- Причина, вероятнее всего, ожидаемая: текущая импортированная база Draft покрывает только 05.10–24.10.2026, а редактируемая историческая карточка находится вне этого периода.
- Date-specific lookup остаётся обязательным: если в локальной базе нет строки расписания на дату карточки, маршрут/время/тип ВС не должны подменяться строкой другого периода. Когда будет импортировано расписание, покрывающее историческую дату, тот же механизм должен заработать и в истории.

Код приложения не изменялся. Следующая правка кода — только после нового слова «Программируй».
