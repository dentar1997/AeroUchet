# 05.10 02:43 · ChatGPT · Причина бага календаря выполнения
- **Денис:** после «Программируй» уточнил ожидаемый сценарий: вводит номер рейса, открывает календарь, календарь показывает дни выполнения.
- **Найдено в live main v132:** верхний контрол даты в `FlightScheduleDatabaseV130View` остаётся обычным SwiftUI `DatePicker`. Он не знает о расписании и поэтому показывает стандартный календарь с выбранной датой. Отдельный `FlightExecutionCalendarV131View` с вычисленными execution dates уже существует, но открывается только отдельной кнопкой в карточке `В выбранную дату не выполняется`.
- **Решение:** при точном поиске существующего рейса с однозначным маршрутом верхний календарь должен открывать именно `FlightExecutionCalendarV131View`; без точного номера рейса оставить системный DatePicker. В execution-календаре отдельно различать текущую выбранную дату и остальные реальные дни выполнения. При нескольких маршрутах сохранять route-specific выбор через отдельные варианты, не объединять молча.
- **Сделано:** причина подтверждена чтением live main; код ещё не изменён.
