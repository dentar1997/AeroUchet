# 04.10 13:46 · ChatGPT · Дата карточки привязана к расчётному интервалу
- **Денис:** уточнил отображение времени в карточке перспективного плана. Исходный интервал из PDF (время работы двигателя/перемещения — как написано в файле) остаётся отдельной строкой без самостоятельной даты.

Если этот расчётный интервал переходит через полночь, в первой строке показывается диапазон дат. В серой расчётной строке дата не дублируется — там остаётся только `время — время`.
