# Многострочная дополнительная информация из PDF

**Время:** 04.10.2026 13:51 МСК
**Автор:** ChatGPT

Денис уточнил правило для дополнительной информации из перспективного PDF.

Если текст в PDF разбит на несколько строк, при импорте нельзя автоматически вставлять точку между строками. Перенос строки в PDF сам по себе не означает конец предложения.

Нужно сохранять исходную пунктуацию и соединять строки как продолжение одного текста, если в источнике между ними нет точки.

Пример проблемы: `...повышение. квалификации...` — искусственная точка лишняя.

Код приложения пока не менять без нового слова «Программируй».
