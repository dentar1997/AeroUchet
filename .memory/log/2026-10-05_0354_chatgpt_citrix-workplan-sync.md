# 05.10 03:54 · ChatGPT · Идея автоматической синхронизации планов через Citrix

- **Денис:** прислал запись экрана входа в корпоративный Citrix StoreFront / Citrix Workspace и опубликованное приложение с рабочими планами. Спросил, можно ли сделать так, чтобы АэроУчёт при входе сам забирал все планы работ без ручного переноса. У входа есть основной логин/пароль и отдельный второй фактор/временный пароль.
- **Наблюдение:** это не обычный файл/URL-источник. После StoreFront запускается удалённое приложение внутри Citrix-сеанса; его интерфейс и данные фактически находятся на удалённой стороне.
- **Техническая оценка:** автоматизировать сам GUI Citrix из iOS-приложения ненадёжно и, при наличии второго фактора, полноценный unattended-login может быть специально заблокирован политикой безопасности. Не следует хранить в АэроУчёте секрет генератора одноразовых кодов или пытаться обходить MFA.
- **Предпочтительное направление будущей синхронизации:** найти разрешённый источник данных *до* Citrix-интерфейса — API, web endpoint, выгрузку/файл, календарный feed или иной backend, из которого опубликованное приложение получает планы. Тогда АэроУчёт сможет при запуске выполнять обычный сетевой запрос, хранить разрешённый долгоживущий токен/учётные данные в Keychain и обновлять планы автоматически.
- **Если доступен только Citrix GUI:** рассматривать максимум как отдельную внешнюю автоматизацию/службу, а не как встроенный механизм АэроУчёта; второй фактор всё равно может потребовать участия пользователя.
