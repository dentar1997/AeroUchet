# 04.10.2026 23:00 МСК — Поиск строки расписания для перспективного плана

## Уточнение Дениса
- В перспективном плане рейс нельзя искать только по номеру.
- Для конкретного назначения нужно выбирать строку расписания, действующую именно на дату этого назначения.
- Из этой конкретной строки брать плановое полётное время и тип ВС; они могут отличаться для того же номера/маршрута в другой период.
- Компоновку пока можно хранить как справочную, но не использовать как основную логику карточки.

## Зафиксированное правило
- Lookup расписания: `номер рейса + operational date + маршрут`.
- Дата должна попадать в `validFrom...validTo` и соответствовать `Дни выполнения`.
- Если номер+дата дают более одной строке, маршрут используется как обязательный дисамбигуатор; молча выбирать нельзя.
- Перспективный план и ручное создание/редактирование должны использовать один и тот же date-specific lookup.
- Из найденной строки возвращаются минимум: маршрут, departure/arrival UTC→MSK, flightMinutes и нормализованный тип ВС.

## Статус
- Код не менялся. Реализация — только после новой команды «Программируй».
