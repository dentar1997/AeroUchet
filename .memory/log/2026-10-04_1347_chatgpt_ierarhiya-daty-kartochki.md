# Уточнение иерархии даты карточки перспективного плана

**Время:** 04.10.2026 13:47 МСК

Денис уточнил предыдущую формулировку U15.

Правило отображения даты в первой строке карточки:
1. Если у назначения есть **полётная смена** (третья строка, для рабочего рейса: начало смены = исходное начало −1:00, конец смены = исходный конец +0:30), дата/диапазон дат в первой строке определяется именно интервалом полётной смены.
2. Если полётной смены нет, но есть обычный временной интервал назначения во второй строке, дата/диапазон дат определяется этим интервалом.
3. Если нет ни полётной смены, ни временного интервала (назначение задано диапазоном дат в плане), первая строка показывает диапазон дат из плана, при этом правая дата источника **не включается**: для отображения нужно вычесть один день из конечной даты.

Важно: термин «расчётная смена» здесь неверен. Третья строка — именно **полётная смена**. В самих временных строках дата не дублируется.
