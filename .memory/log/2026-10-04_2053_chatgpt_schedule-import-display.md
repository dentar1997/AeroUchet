# Расписание: одинаковые имена импортируемых файлов

**Дата:** 04.10.2026 20:53 МСК
**Источник:** Денис, проверка v129 на iPad

## Наблюдение
Все выгрузки расписания скачиваются с одинаковым именем `Draft.xls`. На экране `Ещё → Расписание рейсов` список «Загруженные файлы» сейчас показывает исходное имя файла, поэтому несколько разных расписаний будут визуально неотличимы.

## Решение
- Не использовать исходное имя файла как основной идентификатор импортированного расписания.
- Основная подпись импортированного набора должна строиться по фактическому покрытию данных, например `05.10.2026–24.10.2026`.
- Второй строкой показывать полезные метаданные: количество строк и дату/время импорта, например `2 795 строк · импорт 04.10.2026 20:35`.
- Исходное имя `Draft.xls` можно оставить только как второстепенную служебную информацию либо вообще скрыть из основного списка.
- Логика импорта/дедупликации должна зависеть от содержимого/устойчивых ключей, а не от имени файла.

## Статус
Согласовано для следующего пакета. Код не менять до нового слова «Программируй».
