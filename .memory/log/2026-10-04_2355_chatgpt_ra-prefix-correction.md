# Уточнение префикса RA-

## Контекст
Денис уточнил формулировку предыдущего замечания по редактированию бортового номера в карточке задания на полёт.

## Решение
- После очистки пяти цифр регистрации поле не должно показывать одиночный тире.
- Постоянный префикс поля — **`RA-`**.
- При ручной смене типа ВС цифровая часть борта очищается, но `RA-` остаётся видимым.
- Если был введён пятизначный борт, первый Backspace очищает пять цифр до `RA-`.
- Следующий Backspace не удаляет `RA-`, а восстанавливает предыдущие пять цифр борта.

## Код
Не менялся. Реализация ждёт нового «Программируй».
