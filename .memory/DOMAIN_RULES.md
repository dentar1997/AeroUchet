# Правила расчёта и предметная область

Здесь собраны все правила, которые Денис объяснял в чатах, с датой первого появления. Пометка **[ОТКРЫТО]** означает, что правило не подтверждено или не реализовано. Пометка **[в коде vNN]** означает, что правило реализовано в указанной версии.

## 1. Кто пользователь и откуда данные

- Денис — второй пилот, база Шереметьево (SVO), **всё время считается по Москве**: Europe/Moscow, неделя начинается с понедельника.
- Тип ВС — семейство A320/A321. Приложение задумано и для других пилотов, «моей аудитории» (27.09).
- Предыдущее решение — таблица **Numbers «Расчетка коррект+»**: 9 листов, 33 таблицы. Листы: Расчётные часы, История рейсов, Календарный налёт, План работ, Табельный лист, Учёт, Расчёт, Сравнение, Расчётки. Таблица пересчитывалась около часа, поэтому от неё отказались.

**Приоритет при совпадении (28.09):** факт (история .xls) → текущий план (ICS) → перспективный план. Когда тот же рейс появляется в истории, плановая запись вытесняется. Если текущий план из PDF совпадает с календарём, оставляем запись из календаря.
На 30.09 источники **намеренно разведены по отдельным разделам**, чтобы проверять каждый по отдельности. Сводить их вместе решили потом.

Портал, ICS и календарь iPhone могут обновляться с разной задержкой. Время в ICS **не является фактом**: пример — SU1322 2.09 с окончанием 23:12, которого в истории нет. Старые месяцы исчезают из ICS 1-го числа, поэтому история берётся только из .xls или Аккорда.

## 2. Время лега

| Величина | Правило |
|---|---|
| **Полётное время** | Включение → выключение двигателей. Делится по суткам через 00:00 |
| **Лётное время** | Взлёт → посадка. Делится по суткам |
| **Ночь** | **22:00–06:00** (подтверждено 22.09). Считаются полётная, лётная и рабочая ночь |
| **Рабочее время лега** | От «Начала работы» лега до его «Завершения работы» (**правило 28.09**) |
| Начало работы смены | За 1 ч до планового отправления первого лега. Если вылет в 00:30, начало работы в 23:30 предыдущих суток. У 2-го и следующих легов своё «начало работы» = конец рабочего участка предыдущего лега |
| Завершение работы | Предустановка: **выключение двигателей + 30 мин** для последнего лега смены; для не последнего = выключению двигателей. Это **только значение по умолчанию при создании**. Если завершение введено или импортировано, считаем по нему (баг FlightDuty.end исправлен в v108) |

Порядок показателей в карточке (25.09): расчётное → полётное → лётное → рабочее → полётная ночь → лётная ночь → рабочая ночь.

Эталоны из чатов: SVO→OVB ночной — полётное 3:50, лётное 3:20, полётная ночь 3:40, лётная ночь 3:20. Ещё один известный рейс — 7:19 полётного и 6:32 лётного.

## 3. Полётная смена и задание на полёт

- **Леги с одним номером задания составляют одну полётную смену** (25.09). В истории 1029 легов → 575 заданий, **максимум 3 лега в задании** (7 таких заданий).
- Номер рейса содержит 1–4 цифры. Чётные обычно вылетают из Москвы, нечётные — обратные. Номер вида «1438/1439» означает леги одной смены, первым идёт более ранний. В поле «Рейс» у каждого лега хранится **только его собственный номер**.
- Номер задания +1 — это следующая смена после командировки.
- **Разделённая полётная смена («разделёнка»):** номер задания один, но рабочее время состоит из отдельных интервалов по легам. **Отдых между ними не входит в рабочее время.** Без этого правила по всей истории набегало бы +9202 мин к порталу; в 25 заданиях перерыв больше 4 ч. Пример: одно задание, два лега, 15:00–22:10, рабочее время 7:10.
  - В карточке «Разделённая полётная смена» в первом столбце показывается **рабочее время = ¼ длительности перерыва**, через стрелку: `2:41 → 0:40:15`, секунды не терять (28.09, v107).
- Семь заданий, где «фактическое завершение» в портале ≠ выключение + 30 мин: расхождения от −4 мин до +3 ч (номера заданий — в приватном архиве, docs/02). **[ОТКРЫТО — «потом вернёмся»]**
- Итог «Полётная смена» — это сумма рабочего времени легов (название изменено 28.09).
- Последовательность событий лега: начало работы → включение двигателей → взлёт → посадка → выключение двигателей → завершение работы. Каждое событие **не раньше предыдущего**.
- Смена длится максимум 14 ч (15 ч при усиленном экипаже), поэтому событие не может выйти за **вторые сутки**. Третьих суток не бывает.
- Значения по умолчанию при создании вручную: включение = начало + 1 ч; взлёт = включение + 10 мин; посадка = взлёт; выключение = посадка + 10 мин; завершение = выключение + 30 мин для последнего лега, иначе = выключению; начало следующего лега = завершению предыдущего.

### Перспективный и текущий план (времена — это отправление и прибытие)
- Полётная смена = **отправление первого рейса − 1:00 … прибытие последнего + 0:30**, то есть +1:30 к интервалу рейсов (28.09).
- Длительность у рейса в PDF — это полётное время. Между рейсами закладывается около 1 ч на высадку и посадку, его не игнорировать.

## 4. Плановый / внеплановый
- **Внеплановый** рейс: двигатели запускали и выключили без полёта (отказ, погода, закрытие ВП) или был уход на запасной.
- **Для внепланового расчётное время = фактическому полётному**, а не значению из таблицы (25.09). В истории 13 внеплановых.
- При переключении «Плановый → Внеплановый» расчётное время каждый раз становится текущим полётным временем этого лега. Кнопка «вернуть» восстанавливает исходное состояние, включая вид полёта (v100).

## 5. Расчётные часы (нормативное время)
- Это нормативное время лега из таблиц авиакомпании. Платят именно по нему, а не по фактическому полётному, чтобы не было стимула лететь медленнее или быстрее. **Составляет 50%+ зарплаты.**
- Таблицы выходят по сезонам («Лето» — весна-лето, «Зима» — осень-зима) и корректируются поправками («Лето 2026, поправка №6»). Структура: **маршрут → тип ВС (A320/321, B737, A330, A350, B777) → время туда / обратно + примечания**. Время по типам разное: SVO→KUF у A320 и B737 отличается.
- Версии нормативов не меняют уже рассчитанные старые рейсы.
- **Не делятся через полночь**: время целиком относится к дате **начала работы лега**.
- **[ОТКРЫТО]** Неясно, относится ли расчётное время к началу смены, к началу лега или к включению двигателей. В выгрузке 10.11.2021–22.09.2026 нет ни одного случая на границе месяца, поэтому проверить не на чем.
- В карточке расчётное время показывается как «время» или «НЕТ ДАННЫХ». В режиме редактирования есть переключатель «Из таблицы» и ручная крутилка.

## 6. Норма налёта
- Норма 80 ч, продлёнка 90 ч (у Дениса подписана). Больше 90 ч летать нельзя.

## 7. Наземные события и отсутствия
| Событие | Как учитывается |
|---|---|
| Явка (подготовка, учёба, задачи) | Рабочее время 1:1, оклад без доплат |
| Резерв (в гостинице у SVO) | Полное рабочее время. Дневной или ночной, примерно 12 ч (9–9?) **[ОТКРЫТО: точные часы]** |
| Резерв в месте жительства («дома») | **4 ч резерва = 1 ч рабочего**. Ночная часть пока тоже 4:1 **[сверить]** |
| Тренажёр КТС (полноразмерный симулятор на гидравлике) | Рабочее время, оклад без доплат |
| Тренажёр суша (выживание на суше), тренажёр вода, обучение (охрана труда и пр.), медкомиссия (**ВЛЭК**, не «ЛЭК») | Оплата по **среднему часовому** |
| Отпуск очередной, учебный (учится в Питере, около 50 дн/год), отпуск 120 дн/год | Оплата по **среднему дневному** |
| Заказанный выходной | Ни на что не влияет |

## 8. Месячный учёт и зарплата
- Рабочая неделя **36 часов**, не 35. Обычный рабочий день = **7:12**, сокращённый = 6:12.
- Норма месяца берётся из производственного календаря РФ. Пример: декабрь 2021 — 158:24 за 22 рабочих дня; апрель 2023 — 144:00. 2027 год: 247 рабочих дней, норма 1774:24, сокращённые дни 20.02, 30.04, 11.06, 3.11.
- **Норма к отработке = календарная норма − отсутствия.** Отсутствия оплачиваются отдельно по среднему. Пример: декабрь 2021, учёба 6:00 → 152:24.
- **Переработка / недоработка** = факт − норма к отработке. Пример: апрель 2023, норма 144:00, факт 110:33 → оклад за 110:33 и недоработка 33:27.
- Рабочее время для оклада складывается из: работа пилотом + командировка + рабочее время пассажирского перелёта + командировка вокруг пассажирского перелёта + явки + резерв + резерв дома + тренажёр.
- Зарплата выплачивается дважды: **аванс 27-го** (за 1–15 число) и **остаток 12-го** следующего месяца с перерасчётом (налёт больше 80 ч оплачивается по повышенной ставке).
- Ставки и правила со временем менялись, поэтому нужны **исторические периоды правил**. **[ОТКРЫТО — модуль «Зарплата» не начат]**
- Сравнение «расчёт приложения vs расчётный лист работодателя» по кодам. **[ОТКРЫТО]**

## 9. Командировки и перелёт пассажиром
- Пассажирский перелёт нельзя рассматривать отдельно от рабочих легов. Нужно определять **командировку до и после**: прилетел рабочим и остался → командировка → улетел пассажиром, и обратные варианты. **[ОТКРЫТО — расчёт командировок не реализован]**
- **Перемещение пассажиром входит в рабочее время** с явки к месту убытия, «не менее чем за 40 мин» до отправления. Время явки нигде не фиксируется, поэтому **начало перемещения = вылет − 40 мин** (решение 29.09).
- Если между концом предыдущего события и началом перемещения есть разрыв, показывается отдельное «Время ожидания». Пример: смена закончилась 09:48, перемещение с 09:55 при вылете 10:35 → ожидание 0:07.
- **Правило из Numbers:** промежуток между пассажирским перелётом и рабочей сменой **< 10 ч не делится на 4**, **≥ 10 ч делится на 4**.
- ФАП (по словам ChatGPT, **приказ №139 утратил силу 01.03.2026, действует №381** — **[проверить]**):
  - сначала пассажиром, потом пилотом без ежедневного отдыха → максимальная полётная смена уменьшается на 50% времени перемещения, включая 40 мин. В карточке: «полётная смена должна быть уменьшена на (перелёт + 0:40)/2»;
  - сначала смена, потом пассажиром → «смена + перемещение ≤ норма смены + 2:00». Эти 2 часа **не равны** праву КВС продлить смену при непредвиденных обстоятельствах. В карточке: «Смена + перемещение: … / лимит: норма смены + 2:00». **Норму смены числом не писать**: она зависит от усиленного экипажа, времени суток и числа легов (10:30…13 ч).
- Пассажирский перелёт и рабочая смена — **отдельные события**, иногда в разные даты, но визуально связанные (тонкая линия слева). У каждого лега свой тип ВС: пассажиром можно лететь и на Boeing.

## 10. Перспективный PDF — правила разбора (28–29.09)
- Шаблон **годами не меняется**, поэтому используется жёсткий парсер под него, резервный не нужен (30.09).
- Отсечь шапку: название, планируемое полётное время, имя, дата генерации. Месяц и год обязательны.
- Таблица из 3 столбцов: **дата | время работы | назначение**. Назначение = жирная основная строка + мелкая дополнительная. Число строк текста не равно числу назначений.
- **Серые горизонтальные разделители** — это тонкие прямоугольники, они задают границы назначения. Если разделитель начинается со 2-й колонки, дата «продолжается вниз».
- Пустая дата наследуется от предыдущего назначения. Пример: отпуск 19.11 и рейс в Самару под ним без даты.
- Диапазон дат без времени: **правая дата не включается**. `05.11 → 19.11` показывать как «05.11–18.11», `25.01 → 01.02` как «25.01–31.01».
- Назначение со временем «с–до» записано **одной датой начала**, даже если переходит через полночь: `09.09 23:00–03:20` → до 10.09 03:20.
- «Ш (B)/(C)» = Шереметьево, терминал B/C. Терминал не терять: брифинги в разных местах.
- «A320» в плане означает подразделение A320/321, а не конкретный тип.
- Накладки дат — это **конфликт**. До сохранения открывается окно конфликтов: оставить / исключить / изменить. Исходник сохраняется целиком, решения обратимы, остаётся пометка «Были конфликты».
- Найденные ошибки: строка итогов месяца сливалась с последним отпуском; основная и мелкая строки дублировались; пассажирский SU1876 и рабочий SU1877 (21.01) склеивались в одну смену, и время рабочего лега терялось; **75 из 175 легов терялись** из-за перевёрнутых координат (исправлено в v120, **на iPad не проверено**).

## 11. Производственный календарь
- Только РФ. Источник для будущих лет — API isDayOff (`cc=ru`, `pre=1`; 0 — рабочий, 1 — выходной, 2 — сокращённый; 101/404 — данных нет).
- **Итоговое решение (23.09):** встроенных календарей нет, автосинхронизации нет, всё вручную в «Ещё → Производственный календарь». Кнопки: «Загрузить производственные календари» → «Найти календарь 2027» → «Загрузить недостающие» → «Обновить календарь 2027», плюс «Удалить все календари». Самопроверка года: РФ, 365/366 дней, валидные коды, хеш.
- Официальные названия праздников по ст. 112 ТК РФ.
