## Общие уроки
- Сначала читать актуальный код в main, потом править. ChatGPT не раз правил по памяти и ломал работающее.
- Для визуальных багов смотреть видео покадрово и искать настоящую причину, а не подгонять размеры.
- Сверять расчёты с реальной выгрузкой портала: это лучший тест.
- Не смешивать источники данных (справочник аэропортов ≠ история полётов; пример с PKC).
- Приоритет по смыслу приложения: сначала то, ради чего оно (расчётные часы → зарплата), потом внешний вид. За 240 изменений число в поле «Расчётное время» так и не появилось, а на вид поля ушло ~15 версий.
- Одна гипотеза — одна версия; откат отмечать в PR. Подгонка без причины давала серии по 10–20 правок (шрифт, свайп, клавиатура).
- Сначала набросок экрана, потом код: микрошаг на каждую реплику дал 44 PR на одну карточку и выброшенные экраны.
- Отложенное записывать сразу в BACKLOG, правила — в `.memory/`: всё, что жило только в чате, терялось при смене чата.
- Новый экран — новый файл, но сначала проверить, что Playgrounds видит его в target (Pre069–Pre070). Файлы больше ~1500 строк в Playgrounds грузятся медленно и ломаются (Pre016, Pre047).
- Перед слиянием импорта — прогон против эталона (175 легов, 166 назначений), а не ожидание, что Денис заметит потерю.
Полный разбор каждого изменения — Private `docs/13_RAZBOR_VSEKH_IZMENENIY.md`.

## 06.10 · Зелёный CI ≠ сборка в Swift Playgrounds
Playgrounds собирает код приложения как код главного потока (default isolation MainActor). `Task.detached` с вызовом обычных функций приложения там не собирается, хотя xcodebuild на GitHub проходит (v136). Фоновую работу делать только с пометкой `nonisolated` всей цепочки вызовов и проверкой на iPad.
- **07.10 v153:** «сделай как в X» = только то, что названо (карточка), а не всё из X (шрифт, размеры). Денис: «шрифт не трогать». Перед переносом вида перечислить, что именно меняется.
- **07.10 v161:** без «Программируй» не запускать даже «маленькую» правку. Если Денис остановил вызов — сначала проверить `git log`, ветки на GitHub и открытые PR, и только потом говорить, что изменилось: прерванная команда могла успеть закоммитить, отправить и открыть PR.
